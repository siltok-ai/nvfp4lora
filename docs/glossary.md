# 术语表

本文解释训练、存储和验证文档使用的术语。

模型来源称为 checkpoint，预处理输出称为 bundle；需要继续优化时读取训练检查点，只需应用适配器时读取发布目录。

| 术语 | 含义 | 使用位置 |
|---|---|---|
| family（模型族） | 共享结构与布局约定的一类模型，以显式身份解析 | [注册表](architecture.md#注册表怎样决定模型族) |
| `layout_version` | bundle 或发布格式的版本标识，决定由哪个族读取 | [格式](design/format.md) |
| bundle | 带来源哈希、模型配置、冻结层字节和非流式张量的训练权重包 | [预处理](guides/preprocess.md) |
| 层 store | CPU 上按层号保存并校验冻结原字节的存储 | [流式搬运](design/streaming.md) |
| 槽（slot） | GPU 上可反复装入不同层的有界字节缓冲区 | 同上 |
| streamer（层调度器） | 管理层获取、槽复用与 CUDA 事件的对象 | 同上 |
| 预取（prefetch） | 提前搬运可能使用的层；预测错误只增加搬运 | 同上 |
| phase | 前向或反向提示，用于预测下一层 | 同上 |
| 打包（packed） | 多个低位码值保存在一个字节或连续字节银行中 | [格式](design/format.md) |
| 解码（decode） | 根据码值与缩放得到计算用浮点矩阵 | 同上 |
| NVFP4 | 4 位浮点码值、16 元素块缩放和矩阵全局缩放的组合 | 同上 |
| E2M1 | 1 个符号位、2 个指数位、1 个尾数位的 4 位格式 | 同上 |
| E4M3 | 1 个符号位、4 个指数位、3 个尾数位的 8 位格式 | 同上 |
| 块缩放 | 每 16 个 NVFP4 元素共用的 E4M3 缩放 | 同上 |
| 全局缩放 | 每个矩阵的 FP32 因子，NVFP4 字段为 `weight_scale_2` | [数值策略](design/numerics.md) |
| FP8 per-tensor | FP8 权重使用一个矩阵级缩放，区别于 NVFP4 块缩放 | 同上 |
| W4A16／W8A8 | 权重与激活分别按 4/16 位或 8/8 位参与计算 | 同上 |
| C3 | MoE 的注意力投影和共享专家 LoRA 范围，不含路由专家 | [专家模型](design/moe.md) |
| 专家 LoRA | 每个路由专家各自持有的六个低秩参数矩阵 | 同上 |
| D-ALL／D-ATTN | dense 的全部层内量化投影／仅其中注意力投影 | [密集模型](design/dense.md) |
| GDN | 门控 Delta 网络，模型中的线性注意力模块 | [数值策略](design/numerics.md) |
| GQA | 多个 query 头共享较少 key/value 头的分组查询注意力 | 同上 |
| SDPA | PyTorch 缩放点积注意力接口 | 同上 |
| efficient／math | SDPA 的高效融合后端／数学组合后端 | 同上 |
| 激活检查点 | 保存重算所需输入，以反向重算减少激活显存 | [训练时序](architecture.md#一个优化器步怎样执行) |
| 训练检查点 | 参数、优化器、调度器、随机状态和数据游标的恢复包 | [适配器与状态](design/adapters.md) |
| 发布（publish） | 绑定基座身份的适配器参数，供独立重建使用 | 同上 |
| ΔW 指纹 | 对缩放后的 `B @ A` 权重增量计算哈希 | 同上 |
| E1 | 冻结张量的存储原字节一致 | [验证指南](guides/validation.md) |
| E2 | 同一数值表达式和配置下原字节一致，包含正负零 | 同上 |
| E3 | 独立或跨精度参考满足指定误差与余弦判据 | 同上 |
| 金丝雀（canary） | 刻意放入训练集的固定新关联，用于验证学习机制 | [训练与评测](guides/training.md#怎样评测适配器) |
| 留出（holdout） | 不参与训练的同一关联的不同问法 | 同上 |
| 回放（replay） | 基座生成的固定答案，用于观测已有输出受扰动程度 | 同上 |
| NLL／nat | 平均负对数似然／使用自然对数时的损失单位 | 同上 |
| 监督 token | 最后一段答案及其终止符对应的有效损失位置 | 同上 |
