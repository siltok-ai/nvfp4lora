## 当前阶段

M1 的32个必需关卡已通过。真实40层前向正常，P5的FP32参考按已记录的离散路由拆分判据验证，原无条件1%失败保留。C3和全部专家r2的短程新进程续训、真实两层梯度，以及发布后全部250/4090个增量矩阵指纹重建已通过；两套配置的2048/4096两步压力训练和逐层重算峰值补测也已通过。

C3与全部专家r2均已完成100个优化器步，10/20/50/100步人工关联留出均为50/50（基座0/50）。C3新进程50→100的完整十项状态/逐步比较均E2，发布重建的全部参数、固定probe及250份ΔW也一致；最终回放NLL为1.17×10⁻⁷。专家r2正在执行完整50→100对照，其step100回放NLL为0.0009931，高于基座，阶段回升与回落均保留。专家GPU发布重建、两套后验诊断、效果门槛和最终交付仍待完成；这是功能观测，当前进程和逐项结果见下方进度记录。

按原FP8 input_scale观测，禁用适配器的训练后端有5个模块超出原尺度，启用C3后有4个，未新增越界模块；最大比值2.514。该结果记录W8A8接入风险，不能代替Speed/FreeToken部署一致性验证。
